This folder is only for your OWN MyPet translation files!

The default translations are included into the plugin file itself.
They are vendored from MyPet-Translations commit 1b79f1fb55e0c6a7a1acb4f07cb0b84148d27e76.
To update them, copy the *.properties files into src/main/resources/locale.

If you are interested in translating MyPet visit:

https://translation.mypet-plugin.de/
